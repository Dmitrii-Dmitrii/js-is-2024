# Use case

### Описание
Создание слайдера изображений с использованием Swiper. Создана интерактивная галерея с изображениями на сайте, которая автоматически пролистывается каждые 5 секунд, имеет бесконечный цикл, и позволяет вручную переключать слайды с помощью кнопок "вперёд" и "назад".

### Шаги
- Пользователь загружает страницу.
- После загрузки DOM, выполняется инициализация Swiper с заданными параметрами:
- Автоплей с интервалом 5 секунд.
- Возможность бесконечного пролистывания.
- Ручное управление кнопками "вперёд" и "назад".
- Одновременный показ одного слайда.
- Пользователь видит первый слайд.
- Через 5 секунд слайды автоматически переключаются.
- Пользователь может нажать на кнопки навигации, чтобы сменить слайд вручную.
